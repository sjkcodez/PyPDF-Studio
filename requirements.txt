# ============================================================
# PyPDF Studio — Python Dependencies
# Install with:  pip install -r requirements.txt
# ============================================================
# Note: The following SYSTEM-LEVEL tools are also required and
# must be installed separately (they are NOT pip packages):
#
#   • tesseract-ocr   → needed by the PDF OCR tool
#     Ubuntu/Debian:  sudo apt install -y tesseract-ocr tesseract-ocr-swa
#     Fedora:         sudo dnf install -y tesseract tesseract-langpack-swa
#     macOS:          brew install tesseract tesseract-lang
#     Windows:        https://github.com/UB-Mannheim/tesseract/wiki
#
#   • libreoffice     → needed by Office → PDF tools (Word, Excel, PPT, ODT)
#     Ubuntu/Debian:  sudo apt install -y libreoffice
#     Fedora:         sudo dnf install -y libreoffice
#     macOS:          brew install --cask libreoffice
#     Windows:        https://www.libreoffice.org/download/
#
#   • ghostscript     → needed for advanced PDF compression
#     Ubuntu/Debian:  sudo apt install -y ghostscript
#     Fedora:         sudo dnf install -y ghostscript
#     macOS:          brew install ghostscript
#     Windows:        https://www.ghostscript.com/download/gsdnld.html
#
#   • libheif / libraw → needed for HEIC and RAW image support on Linux
#     Ubuntu/Debian:  sudo apt install -y libheif-dev libraw-dev
#     Fedora:         sudo dnf install -y libheif-devel LibRaw-devel
#     macOS:          brew install libheif libraw
#     Windows:        (bundled in pip wheels — no action needed)
# ============================================================
